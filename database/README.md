# ثبت اطلاعات بازیکنان دریای پارسی

این پوشه محل فایل دادهٔ بازیکنان است. فایل `players.json` با اولین ثبت‌نام به‌صورت خودکار ساخته می‌شود.

## داده‌های ذخیره‌شده
- `username`: نام کاربری یکتا (فارسی یا انگلیسی)
- `totalProgress`: مجموع مراحل تکمیل‌شده در همه جزیره‌ها
- `wrongAnswers`: تعداد پاسخ‌های غلط
- `loginCount`: تعداد دفعات ثبت ورود
- `firstLogin`، `lastLogin`، `lastUpdated`: زمان‌های ثبت

## راه‌اندازی واسط امن
GitHub Pages امکان نوشتن مستقیم در مخزن را از مرورگر نمی‌دهد. برای همین `worker.js` باید روی Cloudflare Workers اجرا شود؛ توکن GitHub فقط به‌صورت Secret در محیط Worker قرار می‌گیرد و هرگز داخل کد بازی قرار نمی‌گیرد.

1. در Cloudflare یک Worker بساز و محتوای `worker.js` را در آن قرار بده.
2. در تنظیمات Worker، متغیر محیطی محرمانه‌ای با نام `GITHUB_TOKEN` بساز و یک Fine-grained Personal Access Token با دسترسی فقط به Contents: Read and write برای مخزن `mohaddesebehboudi/dorvazhe` به آن بده.
3. آدرس Worker را پس از Deploy نگه دار؛ باید در کد بازی به‌عنوان API endpoint تنظیم شود.

## نکتهٔ مهم درباره نام کاربری
این نسخه نام کاربری را یکتا می‌کند، اما چون رمز یا PIN تعریف نشده، نام کاربری به‌تنهایی هویت فرد را اثبات نمی‌کند. هر کسی می‌تواند نام فرد دیگری را وارد کند. پیش از استفاده واقعی در کلاس، بهتر است برای هر دانش‌آموز یک PIN هم تعریف شود.

## محدودیت فنی
داده‌ها در یک فایل JSON تجمیعی نگهداری می‌شوند. Worker هنگام تداخل نوشتن، چند بار تلاش مجدد می‌کند؛ با این حال برای تعداد زیاد کاربران یا ثبت‌های پرتعداد، پایگاه داده‌ای مانند D1 مناسب‌تر است.
